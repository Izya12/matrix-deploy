

# Matrix + LiveKit Installer (Alpha v0.7.0)

Bash-скрипт для автоматического развертывания сервера **Matrix Synapse** с поддержкой звонков через **LiveKit**. Предназначен для быстрой настройки «семейного» мессенджера или корпоративной связи на собственных мощностях.

> [!WARNING]
> **Это Альфа-версия.** Скрипт находится в стадии активной разработки и тестирования. Используйте на свой страх и риск, желательно на чистых серверах.

## Что внутри

* **Matrix Synapse:** ядро сервера на базе PostgreSQL.
* **Element Web:** предустановленный веб-клиент.
* **LiveKit Server:** движок для реализации современных аудио/видео звонков (MSC3401).
* **Nginx:** преднастроенный реверс-прокси.
* **Certbot:** автоматическое получение и продление сертификатов Let's Encrypt.

## Требования

* **ОС:** Debian 12 (чистая установка).
* **Ресурсы:** Минимум 2 ГБ ОЗУ и 2 ядра CPU.
* **Сеть:** Открытые порты 80, 443 (TCP) и порты для LiveKit (UDP 443, 50000-60000).
* **Домены:** Необходимо два настроенных поддомена (например, `m.domain.com` и `lk.domain.com`), направленных на IP сервера.

## Установка

Запустите скрипт от пользователя **root**:

```
bash <(curl -fsSL https://raw.githubusercontent.com/konvasru-oss/matrix-deploy/main/install.sh)

```

В процессе установки скрипт запросит доменные имена и создаст первого администратора.

## Инструментарий

В систему интегрированы сокращенные команды для обслуживания:

| Команда | Действие |
| --- | --- |
| `matrix-backup` | Резервное копирование БД и конфигов |
| `matrix-reset-password` | Смена пароля любого пользователя |
| `matrix-admin-reset-password` | Сброс пароля встроенного админа |
| `matrix-media-cleanup` | Ручная очистка медиа-кэша (удаление старых файлов) |
| `update-element` | Обновление Element Web до актуальной версии |

## Известные нюансы (Alpha)

* **Идемпотентность:** Повторный запуск скрипта поверх существующей установки может привести к дублированию некоторых конфигов Nginx.
* **Let's Encrypt:** При частой переустановке на один и тот же домен можно поймать лимиты (Rate Limit) от API.
* **Уведомления:** На мобильных клиентах (Android) может потребоваться ручная настройка разрешений на работу в фоне и исключение из режима энергосбережения.
